# voice-clone-prep

**先体检，再花克隆名额。**

[English](README.md)

一句话声音复刻是按"音色"卖的，输入窗口又小得可怜（通常 **5–15 秒**干净语音）。
录错了，一个付费名额就换来一个单薄、带噪、削波的克隆。而常见翻车原因全都能在上传前测出来：

- ⏱️ **时长**不在 5–15 秒窗口内
- 💥 **削波**——录得太热或离麦太近
- 🔇 **静音占比**——长停顿吃掉样本窗口
- 📉 **响度**——太安静，克隆出来又薄又噪

`voice-clone-prep` 纯 JS 解析 WAV（PCM16 / float32，零依赖），给出通过/不通过、原因和改法：

```bash
npx voice-clone-prep my-take.wav
```

## 配套录音要点

安静房间、软表面（衣柜前效果好）、手机开飞行模式、离麦 15–20cm、
用平时说话的自然语气而不是播音腔；录 WAV，不要用微信语音（压缩太狠）。
一次录三条，全测一遍，留最好的一条。
